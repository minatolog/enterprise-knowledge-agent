# RAG-20261112-002-ISSUE-01 接入阶段兼容问题

日期：2026-11-12；状态：已修复。

1. 首次运行 `python -m unittest discover -s tests -p test_app.py -v` 导入失败，NameError: name RAGResult is not defined。原因是 LangGraph 运行时解析 TypedDict 注解，但该类型只在 TYPE_CHECKING 分支导入；直接运行时导入又会形成 service/workflow 循环。修复为运行时使用 Any 别名、静态检查保留真实 RAGResult 类型。
2. 首次 `python -m pip install --dry-run -r requirements.txt` 发现 ResolutionImpossible：原固定 certifi 2026.7.22 与 langchain-core 1.8.0 要求 >=2026.10.19 冲突。修复 requirements 为环境已有 certifi 2026.10.23，并锁定本次新传递依赖；未调整其他已有依赖版本。

修复验证：完整 51 项测试通过，requirements dry-run 成功，pip check 无损坏依赖。详见 [执行记录](../execution_logs/RAG-20261112-002.md)。
