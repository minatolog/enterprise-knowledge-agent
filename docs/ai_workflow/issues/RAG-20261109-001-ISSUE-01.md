## 现象

真实 DeepSeek 问答的前三次调用（`p0-real-q1`、`p0-real-q2`、`p0-real-q3`）答案内容正确，但带有“哦～”“主人，鲸鲸”“鲸鱼娘”等角色扮演/安慰语气，不适合企业知识问答。

## 证据

- `p0-real-q1`：有答案，来源页码正确，但回答含“哦～”。
- `p0-real-q2`：审核委员会宗旨正确，但回答以“主人，鲸鲸帮您查到啦～”开头。
- `p0-real-q3`：无答案题合理拒答，但使用“主人～”“鲸鱼娘”等人设表达。

## 原因

`llm.py` 的 `SYSTEM_INSTRUCTIONS` 中遗留了两条非企业问答指令：

- “你是蓝色可爱女仆装鲸鱼娘，请用可爱的口吻回答问题。”
- “当员工的问题中感到负面心情的时候，你要安慰他们。”

## 修复

- 删除上述两行人设指令，保留“只能使用企业资料、证据不足明确说明、引用编号、不编造来源”等企业问答约束。
- 未修改检索、RRF、Reranker、索引、数据或 API 字段。
