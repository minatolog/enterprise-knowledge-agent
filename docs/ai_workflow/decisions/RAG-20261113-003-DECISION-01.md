# RAG-20261113-003 · 统一前端

日期：2026-11-13。用户已选择 React + TypeScript + React Flow，要求整体风格一致。使用独立 frontend/（React、React DOM、@xyflow/react、lucide-react；开发依赖 Vite/TypeScript/types），package-lock 固定解析结果；不改 Python 依赖。原生 HTML 可避免构建维护，但无法满足本轮已选技术方案；不整体迁移第三方 AI 平台。后续维护成本为 Node 构建、依赖更新与前端回归。

统一应用 Shell、全局 token、导航/标题/侧栏/按钮/状态组件；四视图使用同一 API 与内存状态，避免跳转独立静态页。工作流图固定，不允许新增/删除/重连，以免把视觉编辑当作执行变更。布局仅保存节点坐标，问答仅存内存。
