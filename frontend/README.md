# 制度知识助手（前端）

任务 RAG-20261121-001。React + TypeScript + Vite，同一个界面对接两个后端：

| 知识库 | 后端 | 端口 | 鉴权 |
|---|---|---|---|
| 本地知识库 | `app.api`（`/api/v1`） | 8020 / 8021 | 无 |
| 企业知识库 | `app.enterprise.api`（`/api/v2`） | 8030 | Bearer 令牌（OIDC 或开发令牌） |

在“设置”里切换。切换后新的提问会开新对话。

## 页面

- **问答**：回答里的每个引用编号都能点开右侧“原文”栏，显示该段原文（繁体保持原样），与回答文字重合的部分用黄色标出，便于人工核对。每个回答下方的“证据强度”图显示本次检索到的每段资料的重排分数（对数刻度）和拒答线；低于拒答线时系统直接拒答，并列出最接近的资料。多轮追问会把上文一起发给后端改写成完整问题，界面显示“按上文理解为……”。
- **知识库**：已收录的文件、页码、段数、切分方式，以及当前检索配置（候选数、拒答线、繁简归一方式、模型）。索引格式与配置不一致时会提示重建。
- **检索评测**：读取 `reports/eval/cnooc_retrieval_eval_v1.json`，展示四种检索方式的命中率、拒答线扫描曲线和没检索好的题目。需要先运行 `python eval/run_cnooc_eval.py`。
- **资料管理**（仅企业知识库）：上传、按用户组设置可见范围、发布新版本（显示任务状态）、撤回、查看解析失败的文件、在发布历史之间切换。
- **设置**：知识库选择、企业令牌（默认只保留到关闭标签页）、引用段数、是否把对话保存到浏览器。

## 运行

```sh
npm install --prefix frontend      # 本次移除了 @xyflow/react，需要刷新 package-lock
npm run build --prefix frontend
python -m uvicorn app.api:app --host 127.0.0.1 --port 8021      # 打开 http://127.0.0.1:8021/studio/
```

企业服务同样会在 `/studio/` 提供构建好的前端（只有 `/api/v2` 可用，设置里选“企业知识库”）。

开发：分别在 8020 启动 `app.api`、8030 启动 `app.enterprise.api`，再 `npm run dev --prefix frontend`。Vite 把 `/api/v1`、`/health` 转发到 8020，`/api/v2` 转发到 8030。

测试：`npm test --prefix frontend`（会话存储校验、引用编号映射、繁简对照高亮、多轮历史）。

## 设计

海图纸色底、深海墨色文字、深蓝表示结构，黄色只用于在原文里标出证据。回答和原文用宋体，界面用黑体。支持深色模式、键盘操作、减少动态效果；窄屏下导航变为抽屉，原文栏变为底部面板。没有远程字体和 CDN。
